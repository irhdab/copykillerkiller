# 실행 환경 판정과 등급별 절차

이 스킬은 특정 대화형 도구에 종속되지 않는다. 파일을 읽고, 셸을 실행하고, 결과를 해석할 수 있는 환경이면 같은 문서와 같은 스크립트를 쓴다. 다만 사용할 수 있는 도구가 다르므로 시작할 때 등급을 정하고, 그 등급에 맞는 경로로 진행한다.

## 판정

```sh
python3 "<스킬 폴더>/scripts/capability.py"
```

`tier`, `checks`, `docx_comment_copy`, `next_step`을 JSON으로 돌려준다. 셸에서 이름만 필요하면 `--tier-only`를 쓴다. 스크립트를 실행할 수 없는 환경이면 아래 표를 읽고 직접 등급을 정한다. 판정 결과는 검토 결과의 첫머리에 적는다.

## 등급

| 등급 | 조건 | 할 수 있는 일 | 할 수 없는 일 |
|---|---|---|---|
| `full` | Python 3.9 이상, Poppler의 `pdftotext`, 쓰기 가능한 작업 폴더 | PDF 추출, 판본 대조, DOCX 주석 사본 생성, 내부 구조 검증 | 없음 |
| `reduced` | Python은 있으나 `pdftotext`가 없음 | DOCX 대조, 문단 위치 역산, 주석 사본 생성, 구조 검증 | PDF에서 표시 구간을 스크립트로 추출 |
| `manual` | 셸 실행이나 쓰기 권한이 없음 | 원고와 보고서를 읽고 위치별 검토 의견 작성 | 스크립트 실행, 사본 생성, 해시 계산 |

## 등급별 절차

### full

`references/preflight.md`를 그대로 따른다. 보고서는 PDF로 넘기고 `--target-index`로 작업 대상을 지정한다.

### reduced

1. `pdftotext -layout`이 없으므로 PDF 텍스트를 스크립트가 만들지 못한다. 두 가지 중 하나를 고른다.
2. 대화 도구가 PDF 텍스트를 직접 읽을 수 있으면, 페이지 구분자(`\f`)를 유지한 배치 텍스트를 만들어 `.txt`로 저장하고 `prepare_review.py`에 넘긴다. 이때 만든 텍스트가 보고서 전체를 담았는지, 표시 구간의 시작 문구가 원문 그대로인지 확인한다. 줄바꿈과 공백이 원문과 다르면 시작 문구 일치가 깨진다.
3. PDF를 읽을 수 없으면 발췌 목록을 사용자에게 받아 문서 단위로 대조한다. `prepare_review.py` 없이 `find_anchor`와 같은 방식(정규화 후 부분 문자열 위치, 문단 경로 역산)으로 수동 대조하고, 스크립트로 확인한 것이 아님을 결과에 적는다.
4. `blank_text_pages`, `visual_review_required` 같은 신호를 스크립트가 주지 않으므로, 스캔 페이지와 표시 경계는 사람이 확인해야 한다고 밝힌다.

### manual

1. 스크립트를 실행할 수 없으면 해시 계산과 사본 생성이 불가능하다. 원본을 편집하지 않는다.
2. 사용자에게 실행할 명령과 필요한 입력을 그대로 준다.

```sh
python3 prepare_review.py --target-index 1 "상세 결과.pdf" "현재 원고.docx"
python3 create_review_copy.py "현재 원고.docx" --expected-sha256 "<해시>" --notes "주석.json" --out "검토용 주석 사본.docx"
python3 verify_docx.py "현재 원고.docx" "검토용 주석 사본.docx"
```

3. 돌려받은 JSON을 읽고 `references/preflight.md`의 해석 절차를 그대로 적용한다. 실행하지 않은 검증을 실행했다고 쓰지 않는다.
4. 사용자가 파일 작업을 원하지 않으면 위치별 검토 의견 표로 전달한다. 이 경로는 원본을 건드리지 않는다.

## 대화 도구에 따라 달라지는 점

| 항목 | 영향 | 대응 |
|---|---|---|
| 파일 전달 방식 | 첨부, 경로 지정, 본문 붙여넣기로 갈린다 | 경로를 모르면 사용자에게 묻고, 받은 경로를 결과에 적는다. 본문만 있으면 원고를 파일로 저장한 뒤 진행한다 |
| 셸 접근 | 등급을 가른다 | `capability.py` 판정을 먼저 한다 |
| 렌더링 도구 | 최종 DOCX의 쪽 나눔과 글꼴을 확인할 수 있거나 없거나 | 렌더하지 못했으면 확인한 범위를 결과에 적는다. 렌더했다고 쓰지 않는다 |
| 동시 실행 제한 | 긴 PDF에서 중간에 끊길 수 있다 | 스크립트는 입력을 한 번에 읽고 JSON 한 덩어리로 내보낸다. 잘린 출력을 결과로 쓰지 않는다 |
| 스킬 호출 문법 | `$이름` 또는 `/이름` 또는 모델이 문맥으로 선택 | 호출 문법은 결과에 영향을 주지 않는다. 판단 절차는 동일하다 |

## 결과에 남길 것

등급, 실행한 명령, 확인한 판본의 경로와 해시, 확인한 페이지 범위, 실행하지 못한 검증을 적는다. 상위 등급에서 확인한 내용을 하위 등급 결과에 옮겨 적지 않는다.
